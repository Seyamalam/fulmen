# Security policy

## Supported versions

Fulmen is pre-1.0. Only the latest released version receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue. Report privately through GitHub:
**Security → Report a vulnerability** on
[the repository](https://github.com/Seyamalam/fulmen/security/advisories/new).

Include the affected version, a description of the impact, and steps or code
to reproduce. You can expect an acknowledgement within 7 days. Once a fix is
released, the advisory is published with credit to the reporter unless you
ask otherwise.

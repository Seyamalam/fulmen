The code is Apache-2.0. The name **Fulmen** and the Fulmen logo are not. They
belong to Seyamalam, and Section 6 of the Apache License does not grant any
rights to them.

## You may, without asking

- Say your project "works with Fulmen", "is built on Fulmen", or is a "plugin for Fulmen".
- Name a plugin or adapter `fulmen-<something>` on PyPI or crates.io, as long
  as its README states it is not an official Fulmen project.
- Use the name in articles, talks, tutorials and benchmarks.

## You must ask first

- Distributing a fork, modified build or hosted service under the name
  "Fulmen" or a confusingly similar name.
- Using the logo in a way that suggests endorsement.
- Using the name in a company, product or domain name.

## Forks

Forks are welcome under the Apache License. A fork distributed to others must
use a different name and logo, keep the `LICENSE` and `NOTICE` files, and
state that it is derived from Fulmen.
